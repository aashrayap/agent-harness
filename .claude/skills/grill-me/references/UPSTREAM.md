# Upstream provenance

The unified skill is adapted from `skills/productivity/grill-me/SKILL.md` and
the upstream decision-frontier skill in
[`mattpocock/skills`](https://github.com/mattpocock/skills) at commit
`9c9f36ccd3995266cd675468af71639c8dde1ec5`.

Upstream `grill-me` source SHA-256:
`caaf8b8de1684f96e26b28f3c29189db5c89cce4b73e1c93d86164f66ef88637`.
Upstream decision-frontier source SHA-256:
`d2498125dd20a0d3a27f03e0ebcc8e681cf42be468e2d3e3c9e8f5dadcae8d47`.
Upstream `agents/openai.yaml` SHA-256:
`1411d7df7d99b7e621a1ff8283c8133cc2464be63d064e52d8ce169c6800ee9b`.
Upstream `LICENSE` SHA-256:
`0e7ac423bf2c6e223b7c5b156f8cf72da49d748e56a1641402c31f22ad07dbb5`.

Local changes consolidate model and user invocation into one skill while
preserving frontier rounds, docs mode, glossary capture, and ADR format.
The glossary files are named `GLOSSARY.md` and `GLOSSARY-MAP.md`, as in later
upstream releases, instead of the pinned commit's `CONTEXT.md` names.
